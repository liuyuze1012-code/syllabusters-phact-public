# Source documents (not included)

PHACT's knowledge base is built from ASPPH and CEPH documents: the ASPPH AI Framework, the Competency Mapping and
Workforce Training Agenda, the Public Health Leadership report, Shared Vision & Unified Strategy 2024, the CEPH
competency guidelines and others (the full list with sections is in `knowledge-base/sources.json`).

They're ASPPH's published material, so we don't republish them. Get them from the public challenge repo,
https://github.com/12turnbullb/us-breaking-barriers-2026/tree/main/ASPPH , and place them here with the same
folder names to rebuild the knowledge base.
